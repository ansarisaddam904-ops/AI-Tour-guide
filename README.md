# BharatVista AI - Digital Tour Guide for India

A lightweight web app that works as a digital archive and AI-style tour assistant for India:
- State/UT-wise, city-wise, and district-wise discovery
- Culture, heritage, food, history, handicrafts, GI tags, and unique products
- Search and filter experience + built-in chatbot responses

## Run locally

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Project structure

- `index.html` - app structure
- `styles.css` - UI styles
- `app.js` - archive filtering and chatbot logic
- `data/india-archive.json` - curated tourism archive data
